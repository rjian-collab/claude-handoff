# 繁體中文潤稿

請幫我潤稿以下內容：

$ARGUMENTS

## 處理規則

1. 如果上面的內容看起來是一個檔案路徑（例如 `notes.md`、`C:\Users\...\報告.txt`），先讀取該檔案再潤稿；**不要直接改檔**，先把結果給我看。
2. 如果沒有提供內容，請請我貼上要潤稿的文字，不要自己編內容。
3. 依照 `zh-tw-writing` 技能的規範處理：
   - 修正錯字、同音字誤用（例如「在／再」、「的／得／地」、「做／作」）。
   - 所有簡體字轉成繁體字。
   - 中國大陸用語改成台灣用語（例如 软件→軟體、视频→影片、默认→預設、信息→資訊、质量→品質）。
   - 標點符號改用全形：，。、；：？！「」『』（）。引號用「」，引號中的引號用『』。
   - 中文與英文、數字之間加半形空格（例如「使用 Python 3 寫程式」）。
   - 語句不通順處稍微調整，但**保留原意與作者語氣**，不要大幅改寫或增加內容。
4. 專有名詞、程式碼、指令、網址、檔名保持原樣。

## 輸出格式

### 潤稿後全文
（完整的修改後文字）

### 修改清單
用表格列出每一處修改：

| # | 原文 | 修改後 | 原因 |
|---|------|--------|------|

原因請用簡短的分類，例如：錯字、簡轉繁、台灣用語、標點、空格、語句通順。
最後用一句話總結共改了幾處。若原文已經很好，直接說明不需要修改。
