# 台灣繁體中文寫作規範

寫出或修改中文內容時，一律遵守以下規則（除非使用者明確要求其他寫法）。

## 1. 字形：只用繁體字

- 不可出現簡體字。常見誤用：这→這、们→們、个→個、说→說、时→時、为→為、发→發、过→過、么→麼、来→來、对→對、会→會、让→讓、与→與、还→還、没→沒、吗→嗎、应该→應該、实现→實現、问题→問題。
- 注意一對多的簡繁轉換，依語意選字：
  - 发 → 發（發現）／髮（頭髮）
  - 后 → 後（之後）／后（皇后）
  - 里 → 裡（裡面）／里（公里）
  - 只 → 只（只有）／隻（一隻）
  - 干 → 乾（乾淨）／幹（幹部）／干（干擾）
  - 台 → 台、臺 皆可（「台灣」通用；正式文件可用「臺灣」）
- 台灣慣用字：「裡」（非「裏」）、「線」（非「綫」）、「着」→「著」、「群」（非「羣」）、「說」（非「説」）、「為」（非「爲」）。

## 2. 標點：全形

| 用途 | 正確 | 避免 |
|------|------|------|
| 逗號 | ， | , |
| 句號 | 。 | . |
| 頓號（並列詞語） | 、 | , |
| 分號／冒號 | ；：| ; : |
| 問號／驚嘆號 | ？！ | ? ! |
| 引號 | 「」，引號內再引用用『』 | “” ‘’ "" |
| 括號 | （） | () |
| 刪節號 | …… | ... 或 。。。 |
| 破折號 | —— | -- |
| 書名號 | 《》、〈〉 | |

- 中文句子內用全形標點；整句是英文或程式碼時用半形。
- 全形標點前後**不加**空格。

## 3. 空格：中英、中數之間加半形空格

- 正確：「我用 Python 3 寫了 2 個程式」、「在 Windows 11 安裝 Git」
- 錯誤：「我用Python3寫了2個程式」
- 數字與單位：「10 GB」、「5 分鐘」；百分比與度數不加：「50%」、「90°」。
- 英文或數字緊鄰全形標點時不加空格：「我在用 VS Code。」
- 產品名稱保持官方大小寫：GitHub、JavaScript、macOS、iPhone、Windows。

## 5. 語氣與用字

- 動詞後補語用「得」（跑得快），形容詞修飾名詞用「的」（漂亮的花），副詞修飾動詞用「地」（慢慢地走）。
- 「在」表示位置或進行；「再」表示又一次。
- 「做」用於具體動作（做菜、做作業）；「作」用於抽象或固定詞（作者、作業系統、工作）。
- 避免過度使用「進行」（「進行測試」→「測試」）。
- 數字：一般敘述用阿拉伯數字（3 個步驟）；成語、固定用法用中文數字（一石二鳥）。

## 6. 校對時的輸出方式

當你修改使用者的文字時：
1. 保留原意與語氣，不要大幅改寫。
2. 修改後附上修改清單（原文 → 修改後 → 原因）。
3. 程式碼、指令、檔名、網址不翻譯也不改標點。
